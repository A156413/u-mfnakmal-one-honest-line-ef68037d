## Run it

```sh
python3 main.py
```

It writes the line, and nothing else, to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`), with no trailing newline. A hard gate refuses to write if the text is not 1–200 characters or not a single line.
